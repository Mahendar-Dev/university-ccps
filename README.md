## 🗂️ Repository Structure

```
university-ccps/
├── <project-folder>/
│   ├── README.md        # setup and usage for that project
│   ├── screenshots/     # screenshots of the running project
│   └── docs/            # project report (where available)
└── README.md
```

## ▶️ Running a Project

Each project has its own setup steps in its folder README. In general:

| Type | Commands |
|---|---|
| **Node.js** | `npm install` then `npm start` (inside the project or its `backend` folder) |
| **Python** | `pip install -r requirements.txt` then `python app.py` |
| **Java** | Open in an IDE with Maven support, or run `mvn clean package` |
